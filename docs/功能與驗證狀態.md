# 功能與驗證狀態

**一句話：情侶各有一條耐心條，彼此看得到；每個人只能調自己的。**

截至 **2026-11-01**。對應程式：分支 `demo-v1`，commit `dc635f3`，**之後有未 commit 的改動**（見 [待辦](待辦.md)）。環境：iPhone 14 實機、iPhone 18 Pro 模擬器，iOS 18 以上。

為什麼是這樣：[設計決策](設計決策.md)。原始需求：[產品原文](產品原文.md)。

## 已移除（使用者決定）

- **戳一下**：確定不做（現實中對方鬧我，我自己按「我有點煩」）。
- **幫對方充電**：入口已拿掉，但點子保留，列為待做功能（見 [待辦](待辦.md)）。
- 規則引擎仍保留這兩者的計算與單元測試，但**畫面沒有入口**。舊事件的文案仍能顯示。

## 實際驗證過什麼

- **單元測試**：規則引擎 9 項通過。之後引擎有調整，**未重跑**。
- **編譯、安裝、啟動**：實機與模擬器皆可（2026-10-31）。
- **匿名登入**：2026-10-31 用電腦直接呼叫 Firebase 登入介面，回應成功。
- **配對**：兩台裝置配對成功一次（使用者截圖）。
- **版本控制**：已推到 GitHub `Lucashien/patience-bar` 分支 `demo-v1`。

## 已知限制

- **「只能控制自己」目前只有畫面擋，Firestore 規則沒擋**：任一成員仍可改對方的條。使用者要求補上（見 [待辦](待辦.md)）。

- 對方的動作**不會即時更新**我的小工具，要等 app 回到前景或定時刷新（約每 5 分鐘一筆預排時間軸）。
- 小工具按下後先更新本機畫面，**主 app 回到前景才送到雲端**。
- 登入失敗等錯誤仍顯示英文原文。
- 新版 Firestore 規則使用者說明放在草稿、**尚未發布**。
