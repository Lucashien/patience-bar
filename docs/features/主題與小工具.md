# 主題與小工具

## 主題

首頁右上角「⋯」切換，設定存 App Group，小工具跟著換。

| 主題 | 長相 |
| --- | --- |
| A 天氣窗（預設） | 天氣漸層背景、大太陽、特大數字、漸層血條 |
| B 遊戲血條 | 點點底、粗黑框貼紙卡片、10 格血條，顏色依狀態 |
| C 極簡墨水 | 只有設計稿（`design/canvas/`），不做 |

- 含文字的 view 不用 `.shadow` 做立體陰影，改用 `GameSlab`。
- 文字顏色固定用 `Weather.ink`／`AppTheme.gameInk`，不用系統色。雷雨的 `Weather.ink` 是白色，遊戲主題不能用。

## 桌面小工具

小／中尺寸；中尺寸有「我好了」「有點煩」兩顆按鈕；顯示 [[大頭貼]]；約每 5 分鐘一筆預排時間軸。

- 「玻璃／染色」模式系統會抹掉顏色，用 `widgetRenderingMode` 判斷，退回 `.primary` + 透明度。
- 改版後桌面舊實例要移除再重加。
- 對方的動作不會即時更新我的小工具（沒做 silent push）。
