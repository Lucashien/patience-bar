# 耐心條

每人一條 0–100，雙方都看得到，用天氣表示。**每個人只能調自己的，對方的只能看。**

## 天氣

| 範圍 | 天氣 |
| --- | --- |
| ≥70 | 晴 |
| 40–69 | 陰 |
| 15–39 | 快下雨 |
| <15 | 雷雨 |

每種天氣配一句第一人稱的話，文案都在 `Shared/Services/Copy.swift`。

## 動作

| 動作 | 效果 |
| --- | --- |
| 我好了 | +10，上限 100；在上面 |
| 我有點煩 | −10，下限 0；在下面 |

入口：首頁、小工具、Siri（[[主題與小工具]]）。數值常數：`ActionApplier.recoverStep`、`AdjustIntent`。

## 規則

- 值只由本人按鈕改變，**不隨時間回升**（`PatienceEngine.regenPerMinute = 0`）。
- 「每天重設滿格」已決定拿掉，程式還沒跟上（[[已移除與待做]]）。
- 首頁也顯示對方的條與頭像，唯讀。
- 「只能改自己」由 `firestore.rules` 強制，不只靠畫面。
- 最近發生的事：第一人稱事件列表，**不顯示戰績**。

## 數值（含無入口的舊邏輯）

| 項目 | 數值 |
| --- | --- |
| 戳 | 基礎 −3；30 秒內連戳最多 +5；每日上限 40；下限 10 |
| 充電 | 說好話 +10、飲料 +20、抱抱 +15；每日上限 60 |
