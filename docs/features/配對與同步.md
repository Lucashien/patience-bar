# 配對與同步

兩種連線模式：**雙機同步**（Firebase 匿名登入 + Firestore，有 `GoogleService-Info.plist` 才啟用）和**本機模擬**（一支手機扮兩人，可切視角，不用網路）。

## 配對

- 建立者產生 **12 碼邀請碼，同時就是 Firestore 文件 ID**。
- 加入者直接 `updateData` 把自己加進 `members`；規則禁止 list。
- 改邀請碼長度要同時改 app 與 `firestore.rules`。
- 配對時**必須先取暱稱**，最多 8 字；與自己同名時對方顯示「對方」。
- 本機模擬目前可不填暱稱，之後要改成也要先取（[[待辦]]）。

## 資料流

後端 snapshot → `CoupleStore` → `SharedCache` + 重載 widget。
小工具／Siri 的動作先樂觀更新快取、進 `PendingActions` 佇列，主 app 回前景才 `drainPending` 送出（小工具進程沒有 Firebase）。

## 程式

`PatienceBar/CoupleStore.swift`、`FirestoreBackend.swift`、`Pairing/`、`Shared/Services/LocalBackend.swift`、`SharedCache.swift`
