# 大頭貼

每人可設自己的大頭貼，對方與小工具都看得到；沒設時顯示暱稱。

- 首頁選圖 → `AvatarCropView` 裁切 → `AvatarImage.render` 輸出 192×192 JPEG（約 5–10 KB）。
- 直接存在 Firestore 使用者文件的 `avatar` 欄位與 App Group 快取，**不用 Storage**。
- 只能改自己的；「⋯」選單可移除。
- 舊快取沒有 avatars 欄位也能解碼。

## 程式

`Shared/UI/AvatarView.swift`、`PatienceBar/Home/AvatarCropView.swift`、`CoupleBackend.setAvatar`
