## 第一次設定

1. **xcodegen**：Homebrew 太舊時裝不了（舊版不認新 macOS）。改從 GitHub release 下載 `xcodegen.zip`，解壓後直接執行。
2. **Firebase Console**：
   - 新增 iOS app，Bundle ID 填 `com.lucashsien.patiencebar`（**不是** App Group 的 ID，曾填錯）。
   - Authentication 先按「開始使用」，再啟用 **Anonymous**。沒啟用時登入會回 `CONFIGURATION_NOT_FOUND`，app 只顯示一段英文的「internal error」。
   - 建立 Firestore 資料庫。
   - 規則：貼上 `firestore.rules` 並**手動發布**。
3. 下載 `GoogleService-Info.plist`，放到 `PatienceBar/`（已被 `.gitignore` 擋住，不會進 git）。
4. 執行 `xcodegen generate`。**plist 是在 xcodegen 之後才放進來的話，要重新產生專案**，不然不會進 app 包。

## Build 與安裝

- 看有哪些裝置：`xcrun devicectl list devices`。
- **實機**：`xcodebuild build -project PatienceBar.xcodeproj -scheme PatienceBar -destination "id=<裝置 UDID>" -allowProvisioningUpdates`，再用 `xcrun devicectl device install app --device <UDID> <.app 路徑>` 安裝並 `process launch` 開啟。首次可能要在手機的「設定 → 一般 → VPN 與裝置管理」信任開發者。
- **模擬器**：destination 用 `platform=iOS Simulator,id=<模擬器 ID>`，並加上 `CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=YES`。
  - **不要**用 `CODE_SIGNING_ALLOWED=NO`：entitlements 會被拿掉，Firebase 登入的 keychain 會出錯（`-34018`）。
- 新增、刪除檔案後要重新 `xcodegen generate`。

## 坑

- **立體陰影**：對含文字的 view 用 `.shadow` 會把文字也複製一份，字會疊在一起。用 `GameSlab`（墊在底下的實心形狀）。
- **深色模式**：預設前景色會變白，疊在淺色背景上看不見。文字顏色固定（`Weather.ink`、`AppTheme.gameInk`），不跟系統。
- **雷雨狀態**：`Weather.ink` 在雷雨時是白色，所以遊戲主題（背景固定淺色）的按鈕不能用它，要用 `AppTheme.gameInk`。
- **`FirebaseApp.app()`**：還沒 configure 時呼叫會印「尚未 configure」的錯誤，造成誤導。改用自己的旗標（`FirebaseSupport.didConfigure`）。
- **小工具快取**：改了小工具畫法後，桌面上的舊小工具要**移除再重新加**才會用新畫法。
- **小工具與 Siri**：動作先寫進 `SharedCache` 的佇列，主 app 回到前景時由 `CoupleStore.drainPending` 送出。小工具進程沒有 Firebase。
- **邀請碼**：12 碼同時是文件 ID，規則要求 `inviteCode == coupleId`；改長度要同時改 app 與 `firestore.rules`。
- **推 `main`**：目前功能在分支 `demo-v1`，`main` 只有 README，合併由使用者決定。
