# 耐心條 — 開發文件

情侶共用的耐心血條：讓藏在表面下的煩躁、疲累被對方看見，而且幾乎不用手動設定。

**目前：demo 階段。每個人只能調自己的耐心，對方的條只能看。**（截至 2026-11-01）

## 語氣原則（使用者明說，改文案前先對照）

- 文字第一人稱、說需求，例如「先讓我冷靜一下」。
- 不寫「你很煩」「你害我扣血」。
- 不顯示「誰扣了幾次」之類戰績。
